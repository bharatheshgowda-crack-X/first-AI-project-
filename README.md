## 📌 Problem Statement

Many engineering students don't know which skills to learn at each stage of college. They waste time on random tutorials and reach placement season unprepared. This project gives them a **clear, semester-wise skill roadmap** for their branch.

## ✨ Features

- 🎯 Select your **engineering branch**
- 📅 Choose your **semester (1-8)**
- 📋 Get **recommended skills** for that exact stage
- 🚀 Includes career-focused milestones such as projects, internships, capstone, and startup & innovation
- ⚡ Fast, simple, clean interface
